# Task Master Frontend

This is the frontend for the Task Master application. The frontend is built using Next.js and Tailwind CSS.

## Technologies Used
- Next.js
- Tailwind CSS
- Axios

## Pre-requisites
- Before running the task master frontend you should have started the task master backend. You can find the instructions on how to start the task master backend [here](https://github.com/RashmikaJayasooriya/Task-Master-Backend)

## Installing the Task Master Frontend
Download the project from the repository and navigate to the project directory and install the dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

## Running the Task Master Frontend
First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to access the task master frontend.
